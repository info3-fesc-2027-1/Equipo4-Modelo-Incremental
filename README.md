Joyería Posa

Proyecto de Informática III

- Descripción del proyecto

Joyería Posa es una tienda en línea desarrollada para facilitar la consulta de productos de joyería y la gestión de pedidos. El sistema permite a los clientes registrarse, explorar el catálogo, agregar productos al carrito y realizar pedidos con una fecha compromiso de entrega.

Además, cuenta con funciones administrativas para consultar y actualizar el estado de los pedidos.

- Objetivo general

Desarrollar una aplicación web que facilite la administración de clientes, productos y pedidos de una joyería, mediante una interfaz sencilla, organizada y adaptable a diferentes dispositivos.

- Modelo de desarrollo

El proyecto utiliza el Modelo Incremental, que consiste en desarrollar el sistema mediante diferentes incrementos, agregando funcionalidades de manera progresiva.

Cada incremento corresponde a un requerimiento funcional:

* RF1: Registro e inicio de sesión de clientes.
* RF2: Catálogo de productos, búsqueda, filtros y carrito de compras.
* RF3: Creación y registro de pedidos.
* RF4: Consulta y actualización del estado de los pedidos.
